IoT & Automatisering

Smart Home Automatisering

In dit project automatiseerde ik een reeks slimme thuisapparaten via een centrale Raspberry Pi als hub. Verlichtingsschakelaars en een temperatuurregelaar werden aangestuurd via MQTT en Node-RED.

Wat heb ik geleerd?

Ik ontdekte hoe het MQTT-protocol werkt voor lichtgewicht berichtuitwisseling tussen apparaten. Node-RED liet me visueel flows bouwen zonder elke keer code te schrijven. Python-scripts stuurden de GPIO-pinnen aan op basis van inkomende MQTT-berichten.

Aanpak

Een Mosquitto MQTT-broker werd geïnstalleerd op de Raspberry Pi. Node-RED flows werden aangemaakt voor verschillende automatiseringsscenario's zoals het dimmen van lichten bij zonsondergang op basis van de systeemtijd. Bash-scripts zorgden voor automatisch herstarten van de diensten bij stroomonderbreking.

Resultaat

Een functioneel smart-home prototype dat meerdere apparaten centraal aanstuurt. Het systeem start automatisch op bij het booten van de Raspberry Pi en is stabiel in gebruik.

Technische specificaties

  • MQTT Broker: Mosquitto op Raspberry Pi 4
  • Automatisering: Node-RED flows met timer en API triggers
  • Besturing: Python scripts voor GPIO-aansturing van LED's en relais
  • Dashboard: Node-RED dashboard voor handmatige bediening
  • Huidige automatiseringen: Verlichting dimmen bij zonsondergang, temperatuurschakeling, bewegingsdetectie

Gebruikte technologieën

Raspberry Pi · Python · MQTT · Node-RED · Bash · Mosquitto

Hardware

Raspberry Pi 4 · LED's · Relais module · PIR bewegingssensor · DHT22 temperatuursensor
