Python & IoT

IoT Temperatuurmonitor

Met een DHT11-temperatuursensor aangesloten op een Raspberry Pi heb ik een Python-applicatie gebouwd die temperatuur en luchtvochtigheid uitleest, verwerkt en weergeeft in een lokaal dashboard.

Wat heb ik geleerd?

Ik leerde hoe je GPIO-pinnen aanstuurt vanuit Python, hoe je sensordata verwerkt en opslaat als JSON en hoe je een eenvoudige HTTP-API bouwt om data beschikbaar te stellen voor andere apparaten op het netwerk.

Aanpak

Eerst sloot ik de DHT11-sensor aan op de juiste GPIO-pinnen. Daarna schreef ik een Python-script dat elke minuut de sensorwaarden uitleest en wegschrijft naar een JSON-bestand. Een tweede script serveert deze data via een minimale HTTP-server. Een eenvoudige HTML-pagina visualiseert de live data.

Resultaat

Een werkend IoT-systeem dat continu temperatuur en luchtvochtigheid meet en weergeeft. Het project combineert hardware, Linux, Python en netwerken in een praktisch scenario.

Gebruikte technologieën

Python 3 · RPi.GPIO · DHT11-sensor · Requests · JSON · Raspberry Pi
