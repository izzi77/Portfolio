Netwerkontwerp Kantoor

In dit project heb ik een volledig bedrijfsnetwerk ontworpen voor een fictief kantoor met drie afdelingen. Het netwerk werd gesimuleerd en gedocumenteerd in Cisco Packet Tracer.

Wat heb ik geleerd?

Ik heb geleerd hoe je een netwerk opdeelt in subnetten en VLAN's per afdeling, hoe routers communiceren via OSPF en hoe je toegang beveiligt via access control lists. Port security op de switches verhindert ongewenste apparaten.

Aanpak

Ik startte met een netwerktekening op papier: topologie, IP-adresplan en VLAN-indeling. Daarna bouwde ik het netwerk op in Packet Tracer, configureerde de apparaten via de CLI en testte connectiviteit met ping en traceroute.

Resultaat

Een werkend gesimuleerd bedrijfsnetwerk met inter-VLAN routing, OSPF-routering en beveiligde switchpoorten. De volledige configuratie werd gedocumenteerd in een technisch rapport.

Netwerk specificaties

  • Afdelingen: Sales, Administratie, IT
  • VLAN's: 3 aparte VLAN's met inter-VLAN routering
  • Routering protocol: OSPF
  • Beveiliging: ACL's, Port Security, SSH
  • Apparaten: 3 switches, 2 routers, 12 PCs, 3 servers

Gebruikte technologieën

Cisco Packet Tracer · VLAN · OSPF · ACL · STP · SSH

IP-adresplan

  • Sales: 192.168.10.0/24
  • Administratie: 192.168.20.0/24
  • IT: 192.168.30.0/24
  • Server VLAN: 192.168.100.0/24
