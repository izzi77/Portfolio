Linux Webserver op Raspberry Pi

Voor dit project heb ik een Raspberry Pi omgevormd tot een volledig geconfigureerde Linux-webserver met Apache, SSH-toegang op afstand en een firewall via UFW.

Wat heb ik geleerd?

Ik heb geleerd hoe je werkt in de Linux-terminal, hoe je gebruikers en rechten beheert, hoe je diensten start en stopt via systemctl en hoe je een eenvoudige webserver opzet en beveiligt.

Aanpak

Na het installeren van Ubuntu Server op de Raspberry Pi configureerde ik SSH voor veilige toegang op afstand. Apache werd geïnstalleerd en een eenvoudige testwebsite werd gehost. UFW blokkeerde alle onnodig open poorten. Bash-scripts automatiseerden dagelijkse back-ups.

Resultaat

Een volledig werkende mini-webserver bereikbaar op het lokale netwerk. De server draait stabiel, maakt automatisch back-ups en is beveiligd tegen ongewenste verbindingen.

Gebruikte technologieën

Ubuntu Server · Apache2 · SSH · UFW · Bash · Raspberry Pi
